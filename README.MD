# Jepret.in

## About Jepret.in

Jepret.in adalah platform digital photo booth berbasis web yang memungkinkan pengguna mengabadikan momen secara praktis dan menyenangkan melalui kamera, template foto, dan berbagai pilihan desain.

Jepret.in dapat digunakan untuk kebutuhan pribadi maupun acara khusus. Pengguna dapat memilih template, mengambil beberapa foto menggunakan kamera perangkat, kemudian mendapatkan hasil foto yang telah disusun dalam desain photo booth dan dapat diunduh.

Selain photo booth siap pakai, Jepret.in menyediakan layanan Custom Event bagi pengguna yang membutuhkan desain dan pengalaman photo booth yang disesuaikan dengan tema acara, seperti ulang tahun, wisuda, pernikahan, acara kampus, dan berbagai kegiatan lainnya.

## Main Concept

### Personal Photo Booth

Pengguna dapat menggunakan photo booth untuk mengabadikan momen bersama teman, keluarga, pasangan, maupun untuk kebutuhan pribadi.

**Choose Template → Take Photo → Get Photo → Download**

### Custom Event

Pengguna yang memiliki acara dapat mengajukan permintaan photo booth khusus kepada admin.

**Submit Request → Admin Review → Customization → Payment → Event Photo Booth**

Jepret.in menggunakan konsep Software as a Service (SaaS) dengan menyediakan layanan photo booth yang dapat digunakan secara online.

Layanan terdiri dari:

- Free
- Premium
- Custom Event
