# Jepret.in ♡

**Jepret.in — Little Moments, Lovely Memories**

Jepret.in adalah platform digital photobooth berbasis web yang memungkinkan pengguna mengabadikan momen spesial melalui kamera, memilih template foto, dan mengunduh hasil photostrip secara praktis.

## ✨ Fitur Utama

- 📸 **Live Camera** — Mengambil foto langsung menggunakan kamera perangkat.
- ⏱️ **Countdown Timer** — Hitung mundur 3 detik sebelum pengambilan foto.
- 🎨 **Photo Templates** — Pilihan desain photostrip untuk berbagai momen.
- 💕 **Multiple Themes** — Birthday, Graduation, Friendship, Couple, Wedding, Travel, dan Minimalist.
- 📷 **Four-Photo Session** — Membuat photostrip dari empat foto.
- 💾 **Download Photostrip** — Mengunduh hasil foto dalam format PNG.
- 💌 **Custom Event Request** — Formulir permintaan desain untuk acara khusus.
- 📱 **Responsive Interface** — Antarmuka yang dirancang untuk berbagai ukuran layar.

## 🚀 Cara Menjalankan Project

### 1. Clone repository

```bash
git clone https://github.com/RisnaAriyasariHarahap/jepret-in.git
```

### 2. Masuk ke folder aplikasi

```bash
cd jepret-in/frontend-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Jalankan aplikasi

```bash
npm run dev
```

Buka alamat lokal yang muncul di terminal untuk melihat aplikasi.

## 📸 Cara Menggunakan

1. Buka aplikasi Jepret.in.
2. Pilih template favorit.
3. Klik **Mulai Jepret**.
4. Izinkan akses kamera pada browser.
5. Ambil empat foto dengan hitung mundur.
6. Tunggu sampai photostrip selesai dibuat.
7. Klik tombol **Unduh photostrip PNG** untuk menyimpan hasilnya.

## 💌 Custom Event

Jepret.in menyediakan formulir permintaan desain untuk berbagai acara, seperti:

- Ulang tahun
- Wisuda
- Pernikahan
- Gathering
- Acara spesial lainnya

**Catatan:** Pada versi demo, formulir hanya menampilkan konfirmasi di halaman. Pengiriman dan penyimpanan permintaan secara permanen membutuhkan integrasi backend.

## 🔐 Persyaratan Kamera

- Browser harus mendukung akses kamera.
- Pengguna perlu memberikan izin kamera.
- Akses kamera umumnya memerlukan HTTPS atau lingkungan `localhost`.
